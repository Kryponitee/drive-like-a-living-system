## 科学解释与边界

1. **当前直线任务的成功率已接近饱和。** A 和 C 各 90/90，不能以此证明通信有益；B 的一次碰撞也不足以支持稳定的统计差异。
2. **控制效率表现不同。** A 平均 188.14 步、B 129.42 步、C 137.64 步；这不是任务成功率，也不是对安全性的直接量度。应结合轨迹中的踏板和速度曲线分析。
3. **模仿误差与闭环表现不能直接等同。** 先前离线验证损失 A 优于 B 优于 C，但闭环中 C 和 A 都达到 100% 成功，C 的平均用步更少。
4. **独立双踏板允许共激活，但教师的拆分有符号踏板标签从不共激活。** B/C 在闭环中约 25–27% 的场景平均步比例同时达到 T>0.1 且 B>0.1；A 约 2%。该差异值得检验是否存在力的抵消、能量浪费或协调失败；不能仅凭共激活就断定车辆已失控。
5. **不能泛化到曲线道路或真正复杂纵向交通。** 固定零转向、直线地图和当前成功率近饱和限制了实验区分力。

## 推荐的下一项最小因果实验

在**不重新训练**的前提下，对 C 的全部 checkpoint 在同样 30 个测试场景中运行 `block_messages=True` 的消息阻断对照，与正常 C 配对，测定成功率、完成步数、碰撞、奖励和共激活变化。只有这种真实的干预对照，才可初步识别 C 的跨模块通信是否被控制策略使用；此报告不宣称已完成干预。
