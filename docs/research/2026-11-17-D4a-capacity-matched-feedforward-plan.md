# DLS D4a — 容量/数据/优化预算匹配的纯前馈 BC 对照（事前方案）

日期：2026-11-17；承接 D3e，**在观察 D4a 闭环结果之前登记**。

## 科学问题与区分

D3a–e 针对已有 C 网络的冻结权重干预，没有找到跨 3 个种子一致的通信/递归记忆必要性；但隐藏状态逐步清零属于 OOD 干预，不能排除专门训练的无记忆网络反而不能完成任务。D4a 检验 **当前完整259维观测的 BC 任务是否可由一个从头训练的纯反应式网络近似完成**。

## 唯一改变：学习器有无跨步状态

- 对照：D1 C 原始 BC seed42/43/44，原始权重不变。
- 实验：F，严格前馈 MLP，输入259→256→185→2；激活 tanh，输出 tanh。可训练参数 **114477**，相比 C **114390** 多87（0.076%）。
- 数据：与 D1 完全相同的219条成功专家 train episode / 91717步、23条 val episode / 9822步；**不重新采集**。直接复用 D1 ExpertSequences 的40步切片、样本顺序机制、掩码、训练均值/标准差、仅在训练集计算的 normalization。
- 训练：分别 seed42/43/44，8 epochs、batch48、AdamW lr6e-4 weight_decay1e-5、smooth-L1 beta0.1、grad norm 1；以验证 Huber 选择最优 checkpoint；与 D1 相同 optimizer step/episode-chunk 预算。禁止用新闭环测试来选超参数。
- 审计：逐种子记录参数量、step budget、checkpoint/hash、F与C的 normalization 数组一致性。**参数数目匹配不等于训练FLOPs或推理耗时匹配**，明确记录这项限制。
- 测试：保留 MetaDrive0.4.3、地图3、horizon800、density(0,0.1,0.25)。**全新**种子 34000..34023；每个 seed F/C 在相同24场景×3密度、确定性闭环执行；共 432 条新 episode，拆成 54 个8-scene CPU 进程。独立于 D3 的32000..32023以及早期开发测试集。
- 主要指标：密度0.10下每训练seed的闭环成功率差 F−C（同场景）、平均奖励差、route completion；其他两密度为泛化检查。保存逐场景配对结果、失败类型、冻结 C 权重前后 SHA256。
- 解释规则：若 F≈C（成功数差在各seed不超过2/24且奖励不出现一致明显退化），支持“**这套观测/数据任务没有显著强迫循环功能**”，**不**证明记忆对所有驾驶任务无用；若 F 跨3个seed显著落后 C，再调查循环结构与优化/参数化，而非立刻推断需要历史。种子仅三个且场景共用，不能把432条轨迹视为432个独立随机样本做显著性结论。置信区间若提供，需按场景和训练种子成组处理。
