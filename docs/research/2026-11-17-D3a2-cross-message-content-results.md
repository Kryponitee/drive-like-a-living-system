# DLS P0 — D3a2 跨模块内容必要性干预结果

日期：2026-11-17。基于 [D3a 接收方干预](2026-11-17-D3a-message-recipient-results.md) 的后续单点机制测试。执行 [GitHub Actions #44037421039](https://github.com/Kryponitee/drive-like-a-living-system/actions/runs/44037421039)，**SUCCESS**。

## 实验（严格复用旧资源）

D3a 对 C 的消息接收者循环重分配，未观察到性能稳定退化；但分配改变没有消除跨模块消息中的信息。因此 D3a2 进一步检验：**在不改变每个模块消息向量 L2 范数的条件下，将直接跨模块消息换成该模块自己生成的信号，原 BC C 的控制表现是否受损？**

冻结 D1 seed42 C；原模型调用每步 computed `aux_i = \sum_{j≠i} A_{ij} V_j h_j`。仅在向 GRUCell_i 输入前，将 `aux_i` 替换成 `\tilde aux_i = ||aux_i||_2 v_i / max(||v_i||_2, epsilon)`，其中 `v_i=V_i h_i`，从本 tick 快环消息中移除他模块的状态信息。模型其余参数、慢环、路由、解码器、外界观测、场景、动作规则完全不变。所有 replacement 前消息L2能量差最大仅 1.91e-6、原始 step parity误差0；原 BC checkpoint hash不变。**新计算仅48条场景**（C-self ×密度0.1/0.25 ×24种子31000..31023），直接复用D3a的C原始和收者重分配96条场景。

## 完整结果

| 密度 | 指标 | C原始 | C消息收者旋转 | C换成自身消息 |
|---|---|---:|---:|---:|
| 0.10 | 成功/24 | 9 | 11 | **12** |
| 0.10 | 平均奖励 | 284.63 | 287.86 | **296.03** |
| 0.25 | 成功/24 | **4** | **4** | 3 |
| 0.25 | 平均奖励 | 192.12 | 195.06 | **206.11** |

主交通密度0.10下，以同一批场景比 C 原始模型，自身消息替代**多3次成功、奖励平均高11.40**。高交通密度减少1次成功，但奖励平均高13.99。

## 目前可支持和不能支持的结论

**可支持（受限）**：在seed42和这24个场景上，C 的可学习直接通信未显示“必须保留才能驾驶”的任务层证据：重分配接收者不损害，去掉跨模块信号也未稳定损害。原模块结构可以在接受替代信号时保持基本控制。

**不能支持**：
- 此替代使 `v_i` 方向替换已训练的 `aux_i` 方向，仍是对预训练策略的 OOD 干预；不能把好处归结为“通信有害”或“缺少协调更好”。
- 单模型训练随机种子seed42与24场景，不能泛化到所有训练初始化和场景生成分布；同一24种子被多处理组合复用，不可当作独立样本计算置信区间。
- “无需依赖直接通信”不等于“出现闭环反馈补偿”：我们尚未在确定时间段扰动再解除并分析模块间响应和恢复。
