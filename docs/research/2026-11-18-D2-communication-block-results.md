# D2：冻结模型的跨模块通信阻断（因果干预）

日期：2026-11-18

## 实验目标

检验已训练 C 控制器是否**实际利用**跨模块消息，以及消息是否影响两个独立绝对踏板的协调，而非仅凭 C 与 B 的观察性比较推断通信有效。

**单一干预：** C 权重和全部外部输入不变，只在模型推理期将每步全部跨模块消息置零。模型初始状态按场景独立重置，观测归一化、双踏板物理适配器和固定零转向与原评估一致。保留 D1′ 正常通信下的场景基线，逐场景配对。

## 核心结果

所有指标为同一场景与同一训练随机种子下的配对比较。共激活比例定义为每个场景中满足 `T>0.1 且 B>0.1` 的时间步比例，然后对场景取平均。

| 指标 | 正常通信 C | 全部消息阻断 C | 阻断 − 正常 |
|---|---:|---:|---:|
| 成功场景数（90） | 90 | 89 | −1 |
| 碰撞场景数 | 0 | 1 | +1 |
| 成功率 | 100.00% | 98.89% | −1.11 pp |
| 平均步数/场景 | 137.64 | 133.10 | −4.54 |
| 平均每场景奖励 | 111.682 | 111.465 | −0.218 |
| 平均速度（场景平均） | 7.269 m/s | 7.553 m/s | +0.284 m/s |
| 平均油门输出（场景平均） | 0.2710 | 0.2948 | +0.0238 |
| 平均制动输出（场景平均） | 0.1310 | 0.1745 | +0.0434 |
| T/B 同时激活比例 | **24.91%** | **58.85%** | **+33.94 pp** |
| 平均 min(T,B)（场景平均） | 0.0864 | 0.1134 | +0.0271 |

**按训练种子分解共激活：**

| 训练 seed | 正常通信 | 消息阻断 | 增量 |

三个随机种子均出现共激活上升，但幅度差异很大。唯一新增碰撞在**训练 seed 42、场景 seed 30203**，属于交通密度 0.25；其余所有场景成功。交通密度 0、0.10 下，两种条件均全部成功。

## 解释与边界

1. **因果依赖成立（在本实验的干预意义下）。** 对相同的已训练网络仅阻断跨模块消息，双踏板输出统计及闭环轨迹发生改变；因此消息通路不是纯粹装饰性的参数。
2. **对共激活的调节明显，但不能认定已产生生物式协调。** 平均共激活增加 33.94 pp，且 seed44 的依赖尤其显著。消息被使用并不等于信息传递具有最佳的控制价值。
3. **成功率证据有限。** 基线 90/90，消息阻断 89/90，仅一例碰撞；当前直线任务使成功率接近饱和。消息阻断后平均用步更少，但油门、制动同时抬高，不应仅凭用步下降断言整体更优。
4. **完全置零存在分布偏移。** 不可把损害全部归因于“失去有用信息”，因为已训练模块可能只是在依赖非零输入的数值分布。
5. **统计单位需要尊重重复场景结构。** 90 对评估由 3 个训练种子 × 相同的 30 个场景组成，不是 90 个独立训练重复；本结果报告描述性的逐种子差值，不声称显著性检验。

## 下一步：只增加一个判别点

建议 D3 在同一冻结 C 网络上测试**保留消息幅值统计、破坏消息与当前状态的关联**的干预（例如跨场景滞后/错配消息，在相同量级下对照）。目标是将“网络依赖非零消息输入”与“模块传递有针对性的状态信息”区分开来。实施前应检查消息聚合算子：目前 C 对其他七个模块采用均值聚合，简单重排发送者索引不会改变平均消息，不能作为有效扰动。

D2 只回答消息通路对输出及闭环行为是否有作用，尚不能证明语义化信息交换或真正的协作收益。
