# P0 v2.0 — 纵向双踏板运动协调学习

日期：2026-11-17  
状态：D0′执行接口与教师覆盖审计已通过；D1′数据扩展和新模型训练待执行。  
前版：[P0 v1.0](2026-11-16-P0-protocol-v1.md)保留为历史方案，不再作为当前动作接口。

## 1. 唯一研究问题

在车辆转向由外部固定控制器负责时，**一个只输出独立绝对油门和制动的神经运动系统，能否从驾驶反馈中形成可复用、可因果干预验证的内部协调组织？**

研究对象是纵向运动协调，不把当前结果外推为完整横纵向驾驶协调或生物神经系统的直接对应。

## 2. 外部接口

[
u_t=[T_t,B_t],qquad T_t,B_tin[0,1].
]

- (T_t)：独立油门开度，发动机力 (F_e=T_tF_{e,max})；
- (B_t)：独立制动开度，制动力 (F_b=B_tF_{b,max})；
- 两路分别送入物理执行器，不做 (T-B)、符号折叠或互斥；
- 初始P0采用MetaDrive直线路段 `S`，转向固定为0。后续若扩展到弯道，先独立验证固定转向控制器，不把转向并入DLS输出。

输入暂用MetaDrive 259维结构化观测，包含自车状态和交通/道路观测；不使用视觉输入，不把仿真器未来状态或专家动作作为策略输入。

实现：[双踏板适配器](../../src/dls_dual_pedal_adapter.py)；验证：[D0′结果](2026-11-17-D0-prime-dual-pedal-results.md)。

## 3. D0′已确认的前提

- 3个随机种子下，油门能加速、制动能减速，二者同时非零时仍分别到达物理执行器；
- Gymnasium策略接口显式声明为 `Box([0,0],[1,1])`；
- 现有MetaDrive PPO专家在直线地图、交通密度0/.1/.25下12/12成功；
- 1470条初步转移中467条包含制动激活，约31.77%。

教师动作由原专家有符号踏板拆分得到，因此示范中 (T,B) 不同时激活。该事实不妨碍独立执行接口，但不能据此声称学到双执行器同时调节。

## 4. D1′模型比较

保持输入、数据、训练预算和输出接口一致：

| 模型 | 内部结构 | 要回答的问题 |
|---|---|---|
| A | 参数量匹配的单体GRU | 普通循环控制器的基线能力 |
| B | 8个局部循环模块，无跨模块消息 | 共享任务反馈与最终输出汇聚是否已足够 |
| C | 同构8模块，允许跨模块消息 | 直接模块交互是否带来可重复收益 |

B/C采用固定行正交投影 (Pinmathbb R^{259	imes264})，拆成8份33维局部输入；每个模块有49维循环状态和8维消息接口，各自产生一个标量活动，最后经共享解码器生成两个独立Sigmoid输出。模块不预先分配油门/制动职责。

A约114k参数；B/C目标114,880参数，参数差控制在1%以内。保留同一模型初始化种子、训练集、验证集和优化预算。此结构是可干预的候选假设类，不预设它必然形成协调组。

## 5. 数据与训练门槛

D1′计划：
- 地图 `S`，交通密度0/.1/.25；
- 独立采集90个训练episode、30个验证episode、30个测试episode；
- 训练、验证、测试seed严格分离；只用训练成功episode拟合策略，失败episode保留作覆盖审计；
- PPO专家只提供纵向踏板示范，转为 ([T,B])，转向始终由外部零转向控制器执行；
- 3个训练种子 × A/B/C，行为克隆先训练8 epoch，40步序列，Huber损失；保存独立TensorBoard与checkpoint。

D1′只回答模型是否能学会新接口下的基本纵向驾驶。离线拟合好不等于运动协调涌现。

## 6. 后续科学证据门槛

1. **闭环能力**：新seed下成功率、碰撞、出界、速度/间距误差和恢复时间；
2. **组织分化**：模块活动、输出贡献、交互图是否出现稳定但非同质的功能结构；相关性只作诊断；
3. **可复用性**：同一内部组织是否能跨交通密度、初速度和前车行为复用；
4. **因果补偿**：冻结模型后做单模块输出失活、局部观测遮蔽和消息阻断；与损伤规模匹配的随机干预比较，检验其他模块是否补偿任务误差；
5. **对照**：A/B/C均需接受同样干预。只有C优于B且存在可复现的干预交互，才支持直接通信对协调的因果贡献。

D5b–D6c旧接口实验已经表明：随机损伤可诱导相关备份，但未建立稳定的功能分工或失活发送者接管。因此新阶段不重复堆损伤强度，而是先纠正动作接口并建立合适的纵向任务基线。
