# D5a — 冗余运动单元及受损训练：事前实验方案

日期：2026-11-17。地位：设计/预注册；**尚无结果**。沿用 D1 的结构化观测、数据与训练方法，区别于此前 D3/D4a 的实验问题。

## 核心科学问题

当控制接口仅有转向和驱动/制动两个标量时，是否可以通过多对少的冗余运动执行表示，加上可预见范围内的单元损伤压力，让网络学习到有用的、跨场景可复现的故障容错性？

**必要区分**：损伤鲁棒性 != 运动协调组；与更强的命题（任务变量扰动后的功能反馈补偿与可复用协调）相距一步。该实验是“是否存在可学习冗余”的入门门槛，而非正式证明运动协同。

## 唯一改变的变量

在**完全相同的8单元网络结构**、随机种子、D1专家数据和BC训练预算下，比较：
- **clean**：始终无单元失活的BC训练；
- **robust**：每个40步训练序列中固定随机失活掩码；25%不失活、45%随机1个单元失活、30%随机2个不同单元失活。每个训练batch随机抽样（每个序列独立）；模型不知道直接的损伤ID，仅通过最终控制损失梯度优化其余单元及共享特征。

不同训练批次中，同一单位反复可失活；其作用是让模型不能只依靠某个固定执行单元。损伤是乘在**运动单元输出**而非作用在状态输入、共享encoder或最终控制动作。正常与robust的所有可训练参数完全相同。

## 神经执行机构（不预先规定单元功能）

结构化观测259维 → 共享快/慢特征（与原 P0 相同）→ 8个独立的GRUCell动力学单元（隐状态29维，各有独立可学习的标量活动输出）→ 可学习的2×8线性解码W→tanh→MetaDrive 2维控制。

\[
a_{i,t}=\tanh(g_i(h_{i,t})),\quad
u_t=\tanh\left(W\,\left(m\odot a_t\right)\right),
\quad m_i\in\{0,1\}.
\]

- 8是初始容量选择、不是“八块肌肉”；不赋予单元转向/制动角色。
- \(W\) 可学习且不强加语义或正交约束。激活的潜在零空间维度不等于实际利用的协调自由度；训练后需审计W秩、列贡献、单元使用率及塌缩。
- 单元之间不提供直接消息，除了共享车辆反馈和慢环条件；因此如果结果有效，最多说明冗余表征带来的**鲁棒分布式输出**，不能声称直接通信必要。
- 训练只用离线专家动作，**没有在线环境损伤后的恢复梯度**，因此D5a绝不宣称学到了真实“扰动后在线反馈补偿”。若本阶段阳性，再单点引入在线受扰训练与反馈补偿实验 D5b。

## 对照与预算

- 复用 D1 的219训练成功轨迹/91717步、23验证轨迹/9822步、观测归一化；训练和验证场景严格隔离。
- 两组均3训练种子(42/43/44)，8 epochs，batch48，SEQ40，AdamW(lr=6e-4,wd=1e-5)，Huber beta0.1，clipnorm1；相同更新次数；3 GPU并行每张卡一个种子，各组顺序训练，checkpoint以最终第8个epoch为主，不因结果对某组特殊挑epoch。
- 新闭环scene seeds=36000..36023 (不得复用旧测试集)、traffic densities=0/.10/.25；各模型训练种子×场景×密度×模式(无损伤+8种分别永久失活的单单元)，共 3×24×3×2×9=**3888条评估**。36/54/64 worker取决于实际CPU资源，但每模型严格配对场景与损伤类型。
- 每个评估回合从起点施加固定损伤；与训练中的单序列随机损伤不完全同分布，构成更严的泛化测试。保留原C/BC模型作为外部驾驶基线（非本实验唯一变量）。

## 评价与预期可证伪结论

主效应为**成功率损伤下降量的差分中的差分**，按模型训练种子和密度分别报告：
\[
\Delta_{s,d,i} =
\bigl(P^R_{s,d,i}-P^R_{s,d,0}\bigr)
-\bigl(P^C_{s,d,i}-P^C_{s,d,0}\bigr).
\]
\(R\)=robust、\(C\)=clean；下标0表示健康状态，i表示失活的一个单元。\(\Delta>0\) 意味 robust 的受损性能相对自身健康状态损失更小。也报告奖励与进度对应变化、绝对受损成功率、正常驾驶的成本、每单元活动与实际输出贡献；保持每训练种子分层，不将重复测试场景误作完全独立样本。

- **支持“学到的冗余有价值”**：robust相比clean，在损伤后有可重复的较小相对损失，且健康驾驶能力没有完全崩溃、W有至少两个非退化方向、多个单元实际承担贡献。
- **否定**：robust在多种子上不能改善受损表现、以牺牲大部分健康驾驶能力为代价、或者完全塌缩到一个通道，都不能支持协同价值。
- **无法从D5a证明**：单元自然功能分化、神经协同组织、真正的在线反馈补偿、或驾驶自然涌现。如果有效，下一步D5b引入受损后动态恢复与反馈阻断对照；如果无效，首先审计能否通过BC优化得到正确的冗余分配，再决定是否在线训练。
