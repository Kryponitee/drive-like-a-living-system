# D3c：重新训练下的模块配对功能判别

日期：2026-11-19  
状态：**训练、模型校验与结果聚合成功；严格的9/9配对恢复门槛未通过。**

## 问题与实验设计

D3b的消息置换更接近“是否存在已训练通信边”的检查，功能混合偏导则在有通信的可加目标下出现强阴性阈值困难。D3c改为反事实重训练：对相同D3a数据，在三种完备两两配对及无通信结构上分别从头训练，不做推理期断边。

唯一实验问题：**如果目标包含已知的互补计算，正确将互补变量分配到同组的连接结构，是否在等预算训练下比错误配对稳定地更容易拟合？若目标仅为独立变量对logit的相加，事先指定的“真值组”是否失去特殊优势？**

使用D3a原始数据与同一`ModularPedalController`类：四个局部观测、每模块一条配对消息、全局线性读出为两个独立Sigmoid踏板输出。三个无向配对：

- P0 = (0,1), (2,3)
- P1 = (0,2), (1,3)
- P2 = (0,3), (1,2)

无通信用 NONE 表示。各模型共享参数容量、70 epoch、Adam(lr=0.003)、batch=512；同一任务/数据seed/初始化seed下固定初始化与随机batch顺序。训练seed 501、502、503；数据seed 42、43、44；任务包括互补计算 interaction 和可加目标 additive。共计 \(3\times3\times2\times4=72\) 个模型。每种训练完成后按验证损失选择最优epoch；在三个配对中按验证集选择最优拓扑，然后使用未用于选择的测试集评估。

自车速度由此前MetaDrive真实轨迹采样；其余物理量按有物理约束的模拟分布生成。**本阶段仍是纵向状态代理任务，不是新的MetaDrive闭环驾驶实验。**

## 核心结果

| 指标 | 互补计算阳性 | 可加目标阴性 |
|---|---:|---:|
| 预设正确配对被验证集选中（9次独立初始化） | **8/9** | **1/9** |
| 预设正确配对为测试集最优（仅事后诊断） | 7/9 | 0/9 |
| 预设配对相对最佳其他配对的平均测试MSE优势 | +0.002733 | −0.0000356 |
| 由验证集选中配对的平均测试MSE | 0.004728 | 0.0000687 |
| 无通信模型的平均测试MSE | 0.023659 | 0.0007958 |

正号“配对优势”表示真值配对测试损失低于所有错误配对的最好一个。可加目标中不存在真正的必需配对，此处使用阳性样本的预设标签作为**安慰剂分组**，不是阴性任务的真实协调组。

按数据seed展开，交互任务的验证集选中次数：
- 数据seed42，真值P1：2/3，实际选择 P0、P1、P1；
- 数据seed43，真值P0：3/3；
- 数据seed44，真值P2：3/3。

可加目标选中阳性预设配对的次数：seed42 为 1/3；seed43、44 均为 0/3。无通信负控的误差大于一些有通信配对，表明即使目标在数学上可加，增加通信也可通过优化/表达能力改善拟合；**不能以“有通信比无通信好”直接判断任务需要协作**。

## 科学判断

1. **支持有条件的配对功能优势。** 对这个特定计算与受限模块架构，在匹配的从头训练条件下，符合互补物理变量的配对多数情况下更适合拟合任务。阳性8/9、阴性标签1/9提供了比D2“断通信性能下降”更有解释力的现象。
2. **未通过最严格预设成功门槛。** 阳性验证集并非9/9正确；测试集事后最优仅7/9。不同训练初始化和数据分布仍会影响功能重配对的优势。Actions的技术SUCCESS不是科学识别门槛通过。
3. **阴性不是统计意义上的零作用。** 可加目标在三种通信拓扑下仍存在拟合差异，但“预设正确配对”没有稳定优势；这说明我们应量化配对优势相对随机分组基线，而不能任意设置一个绝对阈值。
4. **这里识别的是任务支持的最佳结构，而不是冻结网络内部自然形成的组。** D3c为每种拓扑重新训练，且候选组已由人工规定；因此结果**不能宣称已在原DLS C模型中识别出自然协调组**。三数据seed共9次配对筛选，彼此也不是9个独立任务重复；应将其作为校准实验的描述性证据。

## 后续最小研究点

保持目标与数据不变，下一步应追问能否对**固定权重、没有人工组掩码**的模块网络，通过等容量的可训练读出或受控子模块重组恢复功能上稳定的组合，而非再靠消息边恢复已有拓扑。需要首先比较冻结表征下的最优配对和端到端重训练配对是否一致，否则D3c的功能优势无法迁移到自然学习模型的组识别问题。
