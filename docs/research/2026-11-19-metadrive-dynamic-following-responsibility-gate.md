## 3. 场景与实验设计

MetaDrive直线S地图，零转向，双独立物理执行踏板。使用 MetaDrive 官方 BaseManager 管理真实前车，初始车心距离18m。前车目标速度每35步更新：正常对照 5→7→7→6 m/s；急刹实验 5→7→0→6 m/s。

物理地图seed：41001、41002。训练seed：42、43、44。每个模型在对照/急刹实验前70步都使用相同初始条件和控制，代码直接比较每步速度、车距、踏板，全部通过一致性断言。急刹后第90–99步，前车实际速度相对对照平均下降5.368m/s。

传感器验证：同样ego控制下，未放前车和放前车的观测L2均值差1.394；对照和急刹前70步观测差0，第90–99步均值差0.681。因此物理前车及急刹造成的差异确实进入网络259D观察向量。

## 4. 完整控制器表现

严格配对的六例/架构：

| 控制器 | sham 成功/碰撞 | 急刹 成功/碰撞 |
|---|---|---|
| A 单体 | 0 / 0 | 0 / 0 |
| B 8模块无跨通信 | 6 / 0 | 2 / 4 |
| C 8模块有跨通信 | 4 / 0 | 1 / 3 |

A是低速、160步内不能完成目标，不能仅以无碰撞判定更强。对 B/C 而言，急刹暴露出原来普通直线近饱和成功率无法识别的控制能力不足。样本仅有两地图seed × 三训练seed，不足以宣称显著性。

急刹相对sham，在步骤90–99的平均踏板输出变化：
- B 油门 -0.002450，制动 +0.003212；
- C 油门 +0.001279，制动 -0.002035。

幅度均很小。不能根据单一平均值断言每一时刻的正确动作方向，但结合碰撞结果，原控制器缺少有效的急刹反馈响应。

## 5. 模块计算责任响应

由于C/B的双踏板 pre-sigmoid logit 是八模块标量活动的线性读出，对同模型同物理seed下的急刹-sham差异，各模块贡献的变化可严格加总为总logit变化。

定义模块输出抵消率（各样本按幅值加总）：

rho = 1 - sum_t |sum_i Δc_i(t)| / sum_t sum_i |Δc_i(t)|。

| 输出通道 | B 抵消率 | C 抵消率 |
|---|---:|---:|
| 油门logit | 44.1% | 75.9% |
| 制动logit | 45.2% | 80.2% |

当前C的各模块响应的相互抵消更明显，但**抵消不自动等于有害协调**，也不意味着输出责任分解是网络内部机制的唯一因果分解。

为了验证通信贡献，同一C模型前70步保持一致，从第70步才阻断跨模块消息，不训练：
- 健康C：1/6成功，3/6碰撞，双踏板共激活23.76%；
- 消息阻断C：1/6成功，3/6碰撞，共激活44.23%。

简单关闭消息不能修复失败，还增加了踏板共激活；这不是直接证明正常跨模块通信总是有益，因为干预使之后的循环状态进入训练外分布。

## 6. 物理可行性审计

为了不把根本无法躲开的事故误归因为模型不足，另设计带有真实前车速度和真实车距输入的保守规则式 ACC 控制器，仅用作**特权物理可行性参考，不与 A/B/C 做同输入公平排名**。

两地图seed × sham/急刹共4个episode：
- 4/4 成功抵达，0碰撞。
- 急刹下分别用150步、138步完成，实际行进103.56m、94.13m。
- 急刹下最小车身表面间距3.75m、4.05m。
- 未靠永久停车逃避任务。

因此，真实车辆动力学的场景是可完成的。但要进一步排除观测能力限制，仍需要用与学习策略相同的259D观测训练覆盖紧急制动的控制器。
