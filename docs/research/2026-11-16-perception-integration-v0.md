# DLS 记录 003 — 感知接入与训练顺序（待审查）

日期：2026-11-16。状态：建议方案，**感知训练方案未批准、尚无实现或实验**。

## 已确认的上游约束

- 用户已原则认可 [结构方案 v0](2026-11-16-structure-proposal-v0.md)：单个有状态神经运动系统、可学习连接、不预设技能职责、通过反馈检验涌现协调。此认可**不等于**已选定具体网络、稀疏学习算法或平台。
- 最终目标：端到端闭环驾驶；但不必在第一版同时从头训练感知和协调。

## 推荐的三阶段集成

### P0 — 使用结构化状态验证运动协调（隔离感知变量）

高层输入：仿真可用的自车、车道、周边交通、导航等结构化状态（privileged information，**仅研究阶段使用**）。
底层输入：自车速度、横摆角速度及其他实时可测量的本体状态；高层传递的协调信号。
输出：车辆控制。
目的：单独识别协调网络是否能进行闭环运动学习；此阶段**不称视觉端到端**。

### P1 — 接入冻结的预训练视觉感知编码器

`camera -> E_psi (frozen) -> N_theta -> z -> C_phi -> control`。
同时让可测量的本体状态进入底层快环；高层根据执行反馈更新决策。
只训练高层与协调系统（或其必要的小型适配层），以区分视觉感知限制和控制限制。冻结编码器不保证其表征足够支撑任务。

### P2 — 视觉端到端联合微调

解除感知编码器部分或全部冻结，训练 `E_psi, N_theta, C_phi`。
离线阶段可用驾驶示范的行为克隆等监督；闭环阶段需真实/模拟执行及反馈数据，必要时采用交互数据聚合、模仿更新或 RL。**仿真器/真实动力学不必可微**，不等于可以直接通过闭环奖励对环境反向传播。
此阶段才研究视觉表征与协调结构是否共同适应，并与 P1 作严格对照。

## 两条反馈路径

- 快环：自车实时可测量状态 -> `C_phi`，产生当前控制。
- 慢环：视觉、导航、执行反馈 -> `N_theta`，调节 `z`。
- 这只是接口划分；控制频率、编码器种类、感知对象接口、训练损失和评测平台尚未确定。

## 为什么不直接全网从头训练

同时变化感知和运动控制时，失败难以归因：可能是视觉识别、协调学习、闭环策略或数据覆盖。先 P0，后 P1，最后 P2，能隔离三个主要变量；最终目标仍是端到端。

## 最小判断与对照

- P0 可行而 P1 失败：优先检查视觉表征和状态差距，不否定协调结构。
- P1 可行而 P2 无增益：没有必要强行全量联合训练。
- P2 好于 P1：还要比较参数/数据/训练预算及普通端到端基线，不能直接归因于运动协同。
- 闭环指标：道路合规、安全、完成度、扰动恢复；结构是否形成仍需内部干预与跨场景复用验证。
